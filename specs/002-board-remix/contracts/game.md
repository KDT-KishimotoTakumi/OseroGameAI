# ゲーム・画面・Workerの契約

## 共通ルール

- `createRemixMatch(firstPlayer, ruleVersion = 2)`：固定16石とHP50から開始する。旧履歴の復元に限り版1を指定する。
- `available(match)`：合法な着手と回転を返す。版2の着手不能時はパスだけ。終了時は空配列。
- `simulate(match, command)`：入力を変更せず、完全な連続攻撃と次状態を返す。不正な操作は拒否。
- `commit(match, command, expectedVersion)`：版を照合し、同じ `simulate` の結果を確定。版・手数を1増やし、手番は1回だけ切り替える。
- ダメージ0で無攻撃回数+1、正のダメージで0へ戻す。HP0を優先して勝敗を決め、無攻撃10手または双方着手不能ならHP→石数で判定する。

## UI

着手モードと回転モード、選択区画、方向、決定・取消を明示。選択時は反転対象・連鎖数・合計ダメージを表示。予告対象と選択区画は色だけでなく枠・記号・文字で区別する。

HP・手番・操作する色・回転制限・無攻撃カウントを表示。手番案内2秒・演出中・AI思考中・終了後の対局入力を拒否。手番案内後に自動パスまたはAI思考を開始する。キーボードでも選択、方向指定、決定、取消を行える。

## Worker

要求：対局世代、状態版、対局コピー、AI色、難易度、試験用シード。
応答：対局世代、状態版、操作。受信側で一致と合法性を再検査する。
標準800ms・上級1800msを探索上限とし、上限到達時は見つかった合法候補を返す。再開始でWorkerを終了。失敗時の代替操作は合法候補から選び、通常対局を止めない。

## 再戦・保存

通常の再戦では開始条件の先手を反転。AI対戦では人はシアン、AIはオレンジと明示し、先手色を反転することで人とAIの先後を交代する。役割と先手を同時に入れ替えて先後が変わらない状態を作らない。履歴は保存された初期先手で再生し、履歴からの再戦ではその先後を交代する。
旧キーを上書きしない。形式不正の履歴は表示対象から外し、保存失敗でも確定済み対局は維持する。
