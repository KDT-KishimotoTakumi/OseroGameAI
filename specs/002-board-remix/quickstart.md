# 実装後の動作確認手順

状態：新ルールを実装し、以下の項目を単体・4ブラウザ・自己対戦で確認済み。結果は docs/VALIDATION.md を参照。

## 開発環境

Node.js 22.12以上。ルートで `npm install`、`npm run dev` を実行し、表示されたURLを開く。ブラウザ未導入なら `npx playwright install chromium firefox`。Chrome・Edgeは端末に導入したものを利用する。

## 操作確認

1. 2人対戦で初期16石・各色HP50・先手シアンを確認。
2. 着手と回転で予告を選び直し、取消後に盤面・HP・手番が変わらないことを確認。
3. 左右回転、区画外反転、複数段の連鎖を起こし、予告の合計と実ダメージを照合。
4. 連続回転が禁止され、着手不能時は2秒案内後に自動パス、双方不能時は終了することを確認。通常の手番案内も2秒間表示し、入力とAI開始を待つ。
5. HP0、無攻撃10手、HP同点の石数比較、完全同点の引き分けを固定局面で確認。
6. AI対戦を各難易度で遊び、思考中・演出中に再開始して古い結果が適用されないことを確認。再戦で先後が交代することを確認。
7. 別モードの練習で全課題を操作し、失敗時の再試行と通常履歴への非保存を確認。
8. 終局を保存して全手再生。旧履歴との分離、破損履歴の除外、保存失敗時の対局継続を確認。

## 自動確認

`npm run typecheck`、`npm run lint`、`npm test`、`npm run build`、`npm run test:e2e`、`npm run benchmark` を実行。4ブラウザで区画・予告・HP・演出・設定・キーボードを確認する。自己対戦は全局終局と合法性を確認し、思考時間と終了手数を記録する。

`spawn EPERM` がサンドボックスで発生する環境では権限付き実行の承認が必要。失敗や未実行は検証記録へ残し、成功したものだけを完了扱いにする。
