# 画面と内部境界の契約

## 画面・操作

メニューにAI戦・難易度、2人戦、チュートリアル、履歴、設定。
対局画面に盤面・操作色・先後・石数・公開予約・残数・当該対局のイベント。
結果画面に勝敗・石数・終了理由・配置ID・シードと、再戦・再現対局・メニュー。
履歴は結果20件を表示し、全手順再生は提供しない。
チュートリアルは4段階の固定局面、段階のやり直し、メニュー復帰を提供する。

Tabで操作要素移動、盤面は矢印キー、Enterで通常着手または予約候補選択。
Rで予約モード、Escapeで未確定予約キャンセル。確認ボタンはEnter/Space対応。
盤面端の矢印は停止。反転予定はホバーまたはキーボードフォーカス時に表示する。
各マスに座標・石色・合法性・予約の日本語ラベル、状態変化に読み上げ通知を付ける。
予約確認欄は座標、所有色、次の自分の手番で発動、残数、失効条件を表示。
1280 CSS px未満は幅を広げる案内。高さ不足は縦スクロールし極端な縮小をしない。
OS設定またはゲーム内設定が演出軽減なら軽減する。音の再生不可でも視覚と対局を維持。
進行中の新規対局・メニュー移動は破棄確認を表示。確定した着手の取り消しはない。

## ルール境界

入力は状態の写しと通常着手・予約確定・通常パス。出力は新状態と順序付きイベント、またはエラー理由。
ルールはDOM・音・保存・時計へアクセスしない。UIとAIは同じ合法性・遷移処理を利用。

## AI Worker境界

要求: 対局ID、状態版、要求ID、予約を含む状態の写し、難易度、探索予算ms、探索用シード。
応答: 同じ3識別子、有効行動、探索ノード数、時間。
適用前に識別子と合法性を検証し、古い応答・二重応答は破棄する。
離脱・リセット時はWorkerを終了。障害・予算超過時は事前確保した有効行動へ移る。
予約の自動解決はアプリケーションが行い、AIに追加の行動を要求しない。

## 永続化境界

キーは `jiso-reversi.results.v1` と `jiso-reversi.settings.v1`。
版付きJSONを読込時検証。外部送信なし。チュートリアル完了状態と設定を保存する。
