# データモデルと状態遷移

| データ | 制約 |
| --- | --- |
| 座標 | 行・列は0〜7の整数 |
| 盤面 | 64マス。各値は空・シアン・オレンジ |
| 残り予約 | 各色0〜5の整数 |
| 予約 | 各色の待機予約は最大1件。対象座標、所有色、状態（待機・成功・失効） |
| 初期配置 | 8種類、各4石・各色2石、重複座標なし、両色の合法手あり |
| 対局 | 対局ID、状態版、盤面、操作色、プレイヤーと色の対応、最初の操作プレイヤー、予約、残り回数、配置ID、シード、モード、難易度、イベント |
| 結果 | 対局ID、日時、モード、勝敗、各色石数、難易度（2人戦はなし）、配置ID、シード、先手・色対応、終了理由 |
| 保存 | 版番号付き結果配列は最大20件。対局IDで重複を防ぐ。チュートリアルは結果保存対象外 |
| 設定 | 効果音、演出軽減、チュートリアル完了状態 |

## 手番処理

終局確認 → 操作色の待機予約があれば自動解決 → なければ行動受付 → 相手へ交代 → 終局確認。
予約成功・失効とも手番終了。終局が成立したら待機予約を失効し、結果は一度だけ確定。
予約確認時だけ1回消費し、失効時返却なし。双方の同一マス予約は手番順に解決する。
不正行動は盤面・回数・手番を変更しない。状態の更新元は対局コントローラーに限定する。

## 開始条件

配置は盤上の色を含め固定し、盤面中心180度回転による色保持または色交換の対称性を検証。
新規対局・通常再戦は新たに抽選。再現対局は配置IDとシードを保持し、操作プレイヤーの先後と色を交換する。
AI難易度は直前の設定を保持する。候補の具体座標と検証証拠は実装時に記録する。

## 保存エラー

版・型・件数を検証。不正データは対局状態へ適用しない。
保存拒否・容量不足は通知し、そのセッションの対局を継続する。
再読み込み後はメニューへ戻る。進行中対局の自動復元は初期版の要件に含めない。
