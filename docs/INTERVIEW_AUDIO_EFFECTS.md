# 音楽・SE・反転エフェクトの追加

更新日：2026-09-20。状態：A案の実装・検証完了。

## 依頼

音楽、SE、石がひっくり返ったときのエフェクトを追加する。
追加前は着手時の短い電子音と石の回転アニメーションのみで、BGMはなかった。

## Q001：雰囲気と指定音源

- A：近未来風。電子音のBGM、軽快なSE、反転時に光の輪と粒子。
- B：激しいバトル風。速いBGM、重い攻撃音、連鎖で強まる閃光。
- C：落ち着いた雰囲気。静かなBGM、柔らかいSE、控えめな光。
- 「次の音楽」が指定音源を指す場合は曲名・URLを確認する。

回答：A。近未来風の電子音BGM・軽快なSE・光の輪と粒子を採用。特定の音源指定はなく、ゲーム用に作成した旋律・音色をWeb Audioで合成する。

## 実装時の確認事項

BGMとSEの個別設定、ユーザー操作後の再生開始、タブ非表示時の停止、連鎖との同期、演出軽減、再開始時の演出取消、マス寸法の維持を確認する。採用音源の出典・利用条件を記録する。
