# 実装済み・確認結果

更新日：2026-09-20

## PACE-001：自動パスと進行速度

- 置けるマスがない番は中央の案内後に自動パスし、回転は不可。双方とも置けない場合はHP→石数で終了。
- 手番案内を中央に2秒表示し、入力とAI開始を待機。回転・反転は標準900msへ減速し、短450ms・長1400msも選択可能。
- 再開始・練習・履歴への移動で古い待機を取消。版1履歴は旧規則で復元し、新しい対局は版2で保存。
- 単体59件・4ブラウザ44件、型検査・Lint・本番ビルド、AI自己対戦12局が成功。

## AUDIO-001：近未来風の音楽・SE・反転エフェクト

- 110 BPMの電子音BGM、着手・回転・連鎖・勝利のSEを追加。1つの音源コンテキストを共有し、不要ノードとタイマーを解放。
- BGM／SEの独立したオン・オフと音量保存。最初の操作で再生、非表示時は停止・復帰で再開、終局と履歴ではBGM停止。
- 反転位置に自色の光輪と粒子を表示。連鎖段階に同期し、再開始で取り消す。演出軽減時は追加エフェクトを生成しない。
- 単体53件・4ブラウザ36件、型検査・Lint・本番ビルドが成功。音声信号と画面を確認。詳細は [検証記録](VALIDATION.md)、出典は [素材台帳](ASSETS.md)。

## REMIX-002：新ルール実装

- 初期16石、4区画の左右90度回転、着手と回転の選択、区画外への攻撃、複数段の連鎖。
- HP50、反転数によるダメージ、HP0勝利、無攻撃10手でHP→石数→引き分け判定。
- 連続回転の制限、終了後・二重操作・古い非同期結果の拒否。着手不能時の動作は上記PACE-001で自動パスへ改訂。
- 反転対象・段階番号・ダメージの予告、取消、区画の回転演出、段階ごとの反転とHP表示、演出軽減。
- 2人対戦、Worker上の3難易度AI、探索上限と合法代替手、再戦の先後交代。
- 別モードの5つの実操作練習、達成判定・再試行、元の対局への復帰。
- 新ルール専用履歴20局、全手の盤面・HP再生、保存形式検査、旧履歴との分離、効果音と設定保存。
