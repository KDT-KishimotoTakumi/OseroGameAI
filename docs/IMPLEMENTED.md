# 実装済み・確認結果

## FEEDBACK-003：3回目の試遊フィードバックの解消

- 相手の反撃が自分の残りHP以上になる手に、負ける危険の警告を表示。
- 終局後の操作パネルから着手の案内を削除。下へスクロールした状態で決着しても、勝利バナー全体が見える位置へ自動スクロール。
- ルールは変更なし。結果は [VALIDATION.md](VALIDATION.md)。

## FEEDBACK-002：再試遊フィードバックの解消

- 終局後、勝利バナー内に終了理由と再戦ボタンを表示（スクロールなしで再戦可能）。操作パネルの案内を「対局は終了しました。」に変更。
- 攻撃の予告に相手の反撃（次の相手の番の最大ダメージ）を表示。ルールは変更なし。
- [インタビュー](INTERVIEW_PLAYTEST_FEEDBACK.md)、結果は [VALIDATION.md](VALIDATION.md)。

## FEEDBACK-001：試遊フィードバックの解消

- 手番案内をクリック・キー操作で飛ばせるようにした（表示時間2秒・ルールは変更なし）。飛ばした操作は着手にならない。
- 回転の予告に、次の自分の番に狙える最大ダメージ（布石）を表示。
- 決着の一撃の演出中に勝敗表示・結果カードが先に出る不具合を修正。駒画像をページアイコンに設定し404を解消。
- [インタビュー](INTERVIEW_PLAYTEST_FEEDBACK.md)、結果は [VALIDATION.md](VALIDATION.md)。

## AI-005：AI展開の固定とハードの弱点の解消

- 同点の最善手をシードで選択し、毎回同じ展開になる問題を解消。ハード・スーパーハードは探索末端で次の攻撃を見込む評価を追加。深さ・思考上限・ルールは変更なし。
- 揺れ演出中の横スクロールバー出現を修正。要件は [AI難易度](../specs/002-board-remix/ai-difficulty.md)、結果は [VALIDATION.md](VALIDATION.md)。

## AI-004：3段階の難易度

- ノーマル・ハード・スーパーハードを選択可能。1・2・最大4手先を読み、上限800・1800・2500msで完了した深さの結果を採用する。
- 反撃を考慮する探索と枝刈りを追加。Workerと既存の思考取消を維持。単体64件・4ブラウザのAI対戦4件、型検査・Lint・ビルドが成功。詳細は検証記録を参照。

## TDD-001：テスト駆動開発とカバレッジ基準

- VitestのV8カバレッジを導入し、現行の純粋ロジック・対局進行・AI探索・履歴・音声生成を測定対象に設定。行・分岐・関数・行数のすべてを90%以上に満たさない場合、`npm run test:coverage` は失敗する。
- 演出・DOM結合・Workerは単体測定の対象外とし、操作経路をPlaywrightのE2Eで確認する。境界を除外して未検証にするものではない。
- 演出中の操作拒否、世代・版の照合、区画判定と不正方向、音源の解放、着手・回転SEをテストから先に追加した。
- 単体62件・17ファイルが成功。カバレッジは文96.08%・分岐93.67%・関数95.08%・行99.31%。Chromium・Firefox・Chrome・EdgeのE2E 44件も成功。

## PACE-001：自動パスと進行速度

- 置けるマスがない番は中央の案内後に自動パスし、回転は不可。双方とも置けない場合はHP→石数で終了。
- 手番案内を中央に2秒表示し、入力とAI開始を待機。回転・反転は標準900msへ減速し、短450ms・長1400msも選択可能。
- 再開始・練習・履歴への移動で古い待機を取消。版1履歴は旧規則で復元し、新しい対局は版2で保存。
- 単体59件・4ブラウザ44件、型検査・Lint・本番ビルド、AI自己対戦12局が成功。

## AUDIO-001：近未来風の音楽・SE・反転エフェクト

- 110 BPMの電子音BGM、着手・回転・連鎖・勝利のSEを追加。1つの音源コンテキストを共有し、不要ノードとタイマーを解放。
- BGM／SEの独立したオン・オフと音量保存。最初の操作で再生、非表示時は停止・復帰で再開、終局と履歴ではBGM停止。
- 反転位置に自色の光輪と粒子を表示。連鎖段階に同期し、再開始で取り消す。演出軽減時は追加エフェクトを生成しない。
- 単体53件・4ブラウザ36件、型検査・Lint・本番ビルドが成功。音声信号と画面を確認。詳細は [検証記録](VALIDATION.md)、出典は [素材台帳](ASSETS.md)。

## REMIX-002：新ルール実装

- 初期16石、4区画の左右90度回転、着手と回転の選択、区画外への攻撃、複数段の連鎖。

- 連続回転の制限、終了後・二重操作・古い非同期結果の拒否。着手不能時の動作は上記PACE-001で自動パスへ改訂。

- 別モードの5つの実操作練習、達成判定・再試行、元の対局への復帰。
- 新ルール専用履歴20局、全手の盤面・HP再生、保存形式検査、旧履歴との分離、効果音と設定保存。
