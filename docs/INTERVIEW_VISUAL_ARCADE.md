# 画面のゲームらしさと迫力ある演出

更新日：2026-11-10。状態：回答取得済み・実装と検証完了（VISUAL-001）。

## 依頼

仕様と内容は変更せず、画面全体をゲームらしくし、アニメーションに迫力を出す。
不明点はSpec Kitのインタビューで確認する。

## 変更しない範囲（前提）

ルール・AI・履歴・練習課題、画面の文言・ボタン・配置の意味、回転・反転の所要時間（短0.45秒・標準0.9秒・長1.4秒）、手番案内2秒、演出軽減時の挙動。

## Q001：画面の方向性

- A：サイバー・アーケード（ネオン格子背景、発光枠、走査線、太いHPゲージ。シアン×オレンジ維持）
- B：バトル・アリーナ（金属パネル、赤・金）
- C：レトロゲーム（ドット枠、ブラウン管風）

回答：A。

## Q002：追加する演出（複数選択）

- 着手・回転の衝撃波
- 連鎖のフラッシュとCOMBO表示
- ダメージ数値とHPゲージ演出
- 画面の揺れ（勝利時は大きな勝利演出）

回答：着手・回転の衝撃波、連鎖のフラッシュとCOMBO表示、画面の揺れ。ダメージ数値の表示は採用しない。

## Q003：演出の強さ

回答：設定で調整できるようにする。強→中→なしの3段階、初期値は中。

決定：演出設定に「迫力」（強・中・なし）を追加し、端末に保存する。「なし」は追加演出（衝撃波・フラッシュ・COMBO表示・揺れ・勝利演出）だけを止め、既存の石の回転・光の輪・粒子は残す。演出軽減がオンの場合は迫力設定に関係なく追加演出を表示しない。追加演出は既存の演出時間内に重ねて再生し、対局の進行時間を延ばさない。

## 追加依頼（2026-11-10）

- 「○○の勝利」を画面に大きく表示する → 終局後、HPゲージの上に勝者の色で大きく表示。文言は既存の勝敗表示と同じ。
- 設定をもう少し上に表示する → 演出設定を右側パネル最下部から上部ツールバー右端のドロップダウンへ移動。再依頼により、タイトルと同じ高さの画面右上（手番表示の上）へ移動。設定項目は変更なし。

- フォント・背景・駒をもっとゲームらしく（Web画像の取得も可）→ 既に決定済みのA案の範囲で判断：背景は過去に候補記録済みのUnsplash写真（ネオン光跡）、書体はOFLのDela Gothic One／Orbitron、駒は反転・拡大で劣化しないよう作成したSVG。小さい文字は可読性を優先し従来書体を維持。
