# 現行RPG版の実装状況

> 本資料は旧RPG版の実績記録です。利用者の撤去指示により現行仕様ではありません。現在の仕様は [GAME.md](GAME.md)、予定は [PLAN.md](PLAN.md) を参照してください。

更新日：2026-09-19

## 実装済み

- 4英雄拠点、英雄選択、固有スキル、経験値・レベル、仲間連結
- 3ステージの固定地形、クエスト、ランダム勝利条件、120手判定
- 敵襲・敵石・危険地帯を現行対局から削除
- 着手不能時のパス候補と双方着手不能時の自動終局判定
- 盤面を8×8の正方形グリッドに固定し、セル拡大を防止
- 石反転の回転アニメーション（軽減設定対応）
- Web Worker AI、履歴・全手リプレイ、チュートリアル、キーボード操作、英雄画像

## 検証

型検査・ESLint・単体28件・4ブラウザ16件・本番ビルド・開始配置8種・AI自己対戦12局が成功。依頼済みの未完了タスクはありません。実施条件と詳細は [VALIDATION.md](VALIDATION.md) に記録しています。
