# リミックス・オセロ：遊び方と仕様

更新日：2026-09-20。Webブラウザで遊ぶ2人対戦／AI対戦ゲーム。

## 勝ち方

両者HP50。相手の石を1個ひっくり返すと1ダメージ。相手HPを0にすると勝ちます。
ダメージがない番が両者合わせて10手続いた場合、または双方とも石を置けない場合は、残りHP→石数の順で比較。両方同じなら引き分けです。

## 自分の番

1. 「石を置く」か「区画を回す」を選びます。
2. 石を置く場合は白点のマスを選びます。通常オセロと同じく、相手石を挟める場所だけ置けます。
3. 回す場合は左上・右上・左下・右下の4×4区画と、右回り／左回りを選びます。石と空きマスの位置が90度回転します。
4. 黄色の番号で反転予定の石と順番、右側で合計ダメージを確認します。「取り消す」で選び直せます。
5. 「攻撃を決定」で1手を確定します。石を置くことと回転を同じ番には行えません。

## 連続攻撃と回転

置いた石、または回した区画内の自石から8方向に挟みます。区画の外にも攻撃が届きます。
反転した石からさらに挟める相手石があれば、次の段階の反転が続きます。同じ段階は同時判定し、同じ石への重複ダメージはありません。
回転した次の自分の番は石を置きます。置けるマスがない場合は回転できず、案内を2秒表示して自動でパスします。パスは1手として数え、盤面・HPは変わりません。双方とも置けない場合や満盤では、HP→石数で終了判定します。
空区画や変化のない回転も1手。回転回数の上限、HP回復、英雄・地形・ミッション・敵襲はありません。

## モードと操作

- 2人対戦：同じ画面を交代で操作。
- AI対戦：あなたはシアン、AIはオレンジ。ノーマル（1手先）、ハード（相手の反撃まで2手先）、スーパーハード（最大4手先）を選択。評価が同じ手はランダムに選ぶため、同じ打ち方でも毎回展開が変わります。ハード以上は自分の次の攻撃も見込みます。時間内に比較できた深さの結果を採用し、思考上限は順に0.8秒・1.8秒・2.5秒。初期選択はノーマル。
- 最初の先手はシアン。「先後を交代して再戦」で先手を交代。
- 対局では各手番の開始時に中央へ案内を2秒表示します。その間は操作とAIの開始を待ちます。AI対戦では「あなたの番です」「AIの番です」、2人対戦では色名を表示。盤面・何もない所のクリックやキー操作で案内をすぐ閉じられます（閉じた操作は着手になりません）。上部の新しい対局・履歴などのボタンはそのまま押せます。
- 回転を選ぶと、攻撃の予告に「次の自分の番に最大何ダメージを狙える形か」を併記します（回転後の盤面で自分が置ける手の最大ダメージ。相手の手で変わる目安）。
- 勝敗表示・結果カードは、決着の一撃の演出が終わってから表示します。
- 遊び方ガイド：初めて開いたときに7手順のガイドを表示し、HP・盤面・操作・予告と決定・連続攻撃と回転・判定を画面の該当箇所を強調して説明します。最後に「練習モードを始める」か「対局を始める」を選びます。表示中は手番案内とAIを止めます。スキップ・Escapeで閉じ、矢印キーで前後に移動できます。「遊び方ガイド」ボタンでいつでも再表示できます。
- 練習モード：着手、右回転、左回転と取消、3連鎖、HP勝利の5課題。成功してから次へ進み、何度でもやり直せます。元の対局・履歴には影響しません。
- 勝敗表示：対局が終わると、最後の攻撃演出の後にHPゲージの上へ「シアンの勝利」「オレンジの勝利」「引き分け」を勝者の色で大きく表示します（練習モード・履歴再生では表示しません）。勝利演出はこの表示を中心に重ねます。
- 履歴：終了した対局を最大20局保存。前後の手で盤面・HP・ダメージを再生。
- キーボード：矢印でマス移動、Enter／Spaceで選択、Escapeで取消。操作ボタンはTabで移動。
- 演出設定：画面右上（タイトルと同じ高さ）の「演出設定」から開きます。BGM・効果音を個別にオン／オフ、BGM音量・SE音量を調整して保存。演出軽減と速度も選べます。横幅1280px以上を推奨。
- 音声：最初のクリック・キー操作後に電子音BGMが始まります。着手・回転・連鎖・勝利をSEで伝えます。別タブへ移ると一時停止し、戻ると再開。終局・履歴再生ではBGMが止まります。
- 反転演出：石の回転に光の輪と粒子を重ね、連鎖とともに粒子数とSEの高さが増します。演出軽減時は光・粒子を省略し、結果を文字で表示します。
- 迫力：演出設定で強・中・なしを選べます（初期値は中、端末に保存）。着手・回転の衝撃波、連鎖ごとの盤面の閃光と「2 CHAIN!」などの表示、ダメージに応じた画面の揺れ、勝利時の大きな閃光と揺れを重ねます。強ほど大きく、連鎖が伸びるほど派手になります。「なし」は追加演出だけを止め、石の回転・光の輪・粒子は残します。演出軽減がオンなら迫力設定に関係なく追加演出を表示しません。追加演出は回転・反転の時間内に重ねて再生し、進行時間は変わりません。
- 画面：ネオン光跡の写真を減光した背景にネオン格子と走査線を重ね、ゲーム用書体（大見出し・案内・勝敗はDela Gothic One、数値はOrbitron）、エネルギーコア型の駒、発光するパネル、格闘ゲーム風のHPゲージとVS表示のサイバー・アーケード風。文言・配置・マスの寸法は従来どおり。
- 回転・反転の速度は短0.45秒、標準0.9秒、長1.4秒。演出軽減でも対局の手番案内2秒は表示します。練習モードでは課題の説明を優先します。

初期配置は承認された16石（各区画に両色2個ずつ）。詳細は [確定要件](../specs/002-board-remix/spec.md)。履歴は端末のブラウザに保存し、旧ルールの履歴とは別管理です。
