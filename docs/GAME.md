# リミックス・オセロ：遊び方と仕様

更新日：2026-09-20。Webブラウザで遊ぶ2人対戦／AI対戦ゲーム。

## 勝ち方

両者HP50。相手の石を1個ひっくり返すと1ダメージ。相手HPを0にすると勝ちます。
ダメージがない番が両者合わせて10手続いた場合、または双方とも石を置けない場合は、残りHP→石数の順で比較。両方同じなら引き分けです。

## 自分の番

1. 「石を置く」か「区画を回す」を選びます。
2. 石を置く場合は白点のマスを選びます。通常オセロと同じく、相手石を挟める場所だけ置けます。
3. 回す場合は左上・右上・左下・右下の4×4区画と、右回り／左回りを選びます。石と空きマスの位置が90度回転します。
4. 黄色の番号で反転予定の石と順番、右側で合計ダメージを確認します。「取り消す」で選び直せます。
5. 「攻撃を決定」で1手を確定します。石を置くことと回転を同じ番には行えません。

## 連続攻撃と回転

置いた石、または回した区画内の自石から8方向に挟みます。区画の外にも攻撃が届きます。
反転した石からさらに挟める相手石があれば、次の段階の反転が続きます。同じ段階は同時判定し、同じ石への重複ダメージはありません。
回転した次の自分の番は石を置きます。置けるマスがない場合は回転できず、案内を2秒表示して自動でパスします。パスは1手として数え、盤面・HPは変わりません。双方とも置けない場合や満盤では、HP→石数で終了判定します。
空区画や変化のない回転も1手。回転回数の上限、HP回復、英雄・地形・ミッション・敵襲はありません。

## モードと操作

- 2人対戦：同じ画面を交代で操作。
- AI対戦：あなたはシアン、AIはオレンジ。ノーマル（1手先）、ハード（相手の反撃まで2手先）、スーパーハード（最大4手先）を選択。時間内に比較できた深さの結果を採用し、思考上限は順に0.8秒・1.8秒・2.5秒。初期選択はノーマル。
- 最初の先手はシアン。「先後を交代して再戦」で先手を交代。
- 対局では各手番の開始時に中央へ案内を2秒表示します。その間は操作とAIの開始を待ちます。AI対戦では「あなたの番です」「AIの番です」、2人対戦では色名を表示。
- 練習モード：着手、右回転、左回転と取消、3連鎖、HP勝利の5課題。成功してから次へ進み、何度でもやり直せます。元の対局・履歴には影響しません。
- 履歴：終了した対局を最大20局保存。前後の手で盤面・HP・ダメージを再生。
- キーボード：矢印でマス移動、Enter／Spaceで選択、Escapeで取消。操作ボタンはTabで移動。
- 演出設定：BGM・効果音を個別にオン／オフ、BGM音量・SE音量を調整して保存。演出軽減と速度も選べます。横幅1280px以上を推奨。
- 音声：最初のクリック・キー操作後に電子音BGMが始まります。着手・回転・連鎖・勝利をSEで伝えます。別タブへ移ると一時停止し、戻ると再開。終局・履歴再生ではBGMが止まります。
- 反転演出：石の回転に光の輪と粒子を重ね、連鎖とともに粒子数とSEの高さが増します。演出軽減時は光・粒子を省略し、結果を文字で表示します。
- 回転・反転の速度は短0.45秒、標準0.9秒、長1.4秒。演出軽減でも対局の手番案内2秒は表示します。練習モードでは課題の説明を優先します。

初期配置は承認された16石（各区画に両色2個ずつ）。詳細は [確定要件](../specs/002-board-remix/spec.md)。履歴は端末のブラウザに保存し、旧ルールの履歴とは別管理です。
