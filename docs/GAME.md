# 時層リバーシ RPG：現行ルール

未来予約と敵襲・敵石イベントを除いた、8×8盤のRPGオセロです。各色2つの英雄拠点を四隅に配置します。

## 行動

白点の通常着手、相手拠点への攻撃、選択英雄の固有スキル、通常パスを1手として扱います。通常着手がない場合はパスが候補になり、双方が着手できなくなると即時に判定します。拠点は防御中の攻撃を1回耐え、次の攻撃で陥落します。生存拠点から上下左右につながる同色石が仲間です。

## 英雄・成長

守護者は陥落していない拠点の防御を回復、斥候は経験値3、魔導士は経験値4、司令官は「5＋現在レベル」の経験値を得ます。各色1回のみ使用できます。通常の反転1個につき経験値1、経験値10ごとにレベルが上がります（最大10）。

## 地形・クエスト

ステージごとに回復地（拠点防御回復）と魔法陣（経験値+3）を固定配置します。各色に同じ3件のクエストを提示し、反転・通常着手・仲間・拠点攻撃から抽選します。敵撃破クエストと危険地帯は廃止しました。

## 勝利

勝利条件は拠点、クエスト、石数から対局開始時に決まります。120手、または双方着手不可で未決着の場合は「生存拠点数→達成クエスト数→石数」の順で比較します。

## 操作・演出

白点または相手拠点をクリックし、矢印キーでマスを移動します。石が反転するときは回転アニメーションを再生し、設定の「演出軽減」またはOSの軽減設定で短縮・無効化できます。履歴は直近20件を保存し、全手リプレイと同条件再戦に対応します。
